# opencode-model-autorouter

Плагин OpenCode V2 с GUI для маршрутизации между эквивалентными chat-моделями разных провайдеров. Учитывает фактические скорость и стоимость завершённых шагов, аккаунтные тарифы и остаток средств из API провайдеров, публичные цены с сайтов провайдеров без входа в аккаунт, приоритет бесплатных моделей и временную недоступность после ошибок лимита.

## Возможности

- Автоматически сканирует включённые модели подключённых провайдеров и повторяет сканирование после изменений конфигурации, моделей, credentials, integrations. Запрос `model.list` ограничен типом `chat`.
- Получает тарифы и остаток средств из аккаунтных API провайдеров (OpenRouter, TeamoRouter, PlusVibe) по ключу, уже сохранённому в OpenCode. Ключ разрешается только серверной частью, не отображается в GUI, не передаётся через RPC и не попадает в статус. Публичные прайс-агрегаторы не используются.
- Публичные цены без входа в аккаунт: достаточно указать адрес заглавной страницы любого провайдера (`providerSites`, например `https://openrouter.ai`) — роутер сам найдёт публичный список моделей с ценами и покажет их для моделей без подтверждённого аккаунтного тарифа. Запросы к этим адресам строго неаутентифицированные (без ключей и cookies); цены в нераспознанном формате не отображаются и не выдумываются. Аккаунтный тариф всегда приоритетнее публичного; для точного мониторинга расходов можно дополнительно задать аккаунтный ключ.
- Мониторинг порогов: для каждого провайдера можно задать минимальный остаток и максимальную цену за 1M токенов в валюте аккаунта, чтобы не оказаться без денег на счету. Действие настраивается — только предупреждать либо предупреждать и исключать затронутые модели из роутинга; исключение снимается автоматически, когда значения вернутся в норму.
- Необязательная ориентировка по курсу ЦБ РФ (отдельный флажок): приблизительные эквиваленты «≈» балансов и цен во всех валютах аккаунтов, а при явно включённом флажке — ещё и приблизительное сравнение разных валют в ранжировании `cheapest`. Курсы запрашиваются серверной частью из публичного API ЦБ РФ без credentials. Сравнение через пересчёт — сознательная приближённая оценка: курс ЦБ официальный, а не курс провайдера, фактические расходы могут отличаться; на границы цены и пороги остатка пересчёт не влияет никогда.
- Справка и «О плагине» прямо в панели GUI: сценарии использования (подключение аккаунта, ручной выбор модели, подсчёт затрат, ограничение цен, смена стратегии, сброс), последствия действий и граничные случаи; атрибуция «by nuovogoat» и версия из единого источника; каждое поле настроек поясняет, что оно делает и чем грозит изменение. Документированные отклонения встроенной панели — в `DECISIONS.md`.
- Статистика использования: секция GUI с токенами завершённых шагов по каждой сессии и итого (входные, выходные включая рассуждения, кэш чтение/запись) и финансовыми затратами в реальном времени — по подтверждённому тарифу аккаунта в валюте аккаунта, а без него — по стоимости, измеренной самим OpenCode, в USD; значения не выдумываются, разные валюты не суммируются.
- Необязательный сейф аккаунтных ключей плагина: ключ для OpenRouter, TeamoRouter или PlusVibe можно задать через GUI или RPC вместо connections OpenCode. Ключ шифруется AES-256-GCM в хранилище плагина, отправляется только в аккаунтный API своего провайдера и никогда не возвращается обратно. Провайдерам без подтверждённого аккаунтного API ключ не принимается ни через GUI, ни через RPC: такой ключ некому отправлять, и мёртвая настройка не сохраняется. Сейф не является обязательным: источник ключей по умолчанию — connections OpenCode.
- Автоматически объединяет только модели с одинаковым `id` у разных провайдеров. Совпадения display name и неоднозначные псевдонимы не объединяются.
- Поддерживает ручные группы с разными model ID и `variant`, приоритетом моделей и отдельной стратегией для каждой группы.
- Собирает в памяти TTFB HTTP-ответов, длительность шагов, скорость генерации, фактические `cost` и `tokens`. Для скользящих средних используется `metricAlpha`.
- Распознаёт `402`, `429` и типовые quota/billing/rate-limit ошибки, помещает модель на cooldown и выбирает альтернативу.
- После лимита может автоматически продолжить существующую задачу через synthetic-сообщение, не отправляя пользовательский prompt повторно.
- Показывает в OpenCode Desktop отдельную страницу настроек **Model Autorouter**: полный каталог моделей, включая одиночные модели вне автогрупп, поиск, сортировку и группировки по провайдеру, model ID, route-группе, цене и скорости.
- Позволяет из GUI включать модели в роутинг, выбирать модель и variant для открытой сессии без отправки prompt, создавать ручные группы и менять приоритет моделей.
- Предоставляет RPC `status`, `rescan`, `configure`, `setAccountKey`, `clearAccountKey` и `select`.

## Установка и обновление

```sh
opencode plugin add 'github:nuovogoat/open_code_plugins#main::path:opencode-model-autorouter'
opencode plugin check
opencode plugin update
```

Фиксированная версия:

```sh
opencode plugin add 'github:nuovogoat/open_code_plugins#opencode-model-autorouter/v0.12.0::path:opencode-model-autorouter'
```

История версий: [CHANGELOG.md](CHANGELOG.md).

### Локальная установка

Если `plugin add` не устанавливает git-пакет, скопируйте исходники в каталог плагинов OpenCode (то же, как `project-folder-tabs`):

```powershell
Copy-Item "C:\Tools\open_code_session_marker\opencode-model-autorouter\*" -Destination "C:\Users\Honor\.config\opencode\plugins\opencode-model-autorouter" -Recurse -Force
# исключите node_modules и test-results
opencode plugin list
```

После этого проверьте:
```powershell
opencode plugin list
# ожидается: opencode-model-autorouter  local  C:\Users\Honor\.config\opencode\plugins\opencode-model-autorouter
```

### Обновление локальной копии

Запустите скрипт синхронизации после любого изменения исходников:
```powershell
.\sync-opencode-plugin.ps1
```
Он копирует новые/изменённые файлы, удаляет из установленной копии то, чего нет в репозитории, и исключает `node_modules`, `test-results`. Затем проверьте `opencode plugin list`.

⚠️ **Важно:** не подключайте git-пакет поверх локальной копии — два плагина с одинаковым ID (`opencode-model-autorouter`) конфликтуют. Сначала удалите локальную папку:
```powershell
Remove-Item "C:\Users\Honor\.config\opencode\plugins\opencode-model-autorouter" -Recurse -Force
```

Для локальной разработки укажите каталог плагина в `opencode.jsonc` либо поместите его в `.opencode/plugins/` проекта или `~/.config/opencode/plugins/`.

## Настройка

Параметры передаются через объектную форму записи в `opencode.jsonc`:

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": [
    {
      "package": "./opencode-model-autorouter",
      "options": {
        "enabled": true,
        "autoDiscover": true,
        "strategy": "free-fastest",
        "cooldownMs": 60000,
        "resumeAfterFailover": true,
        "askBeforeOverride": true,
        "metricAlpha": 0.25,
        "rescanIntervalMs": 60000,
        "cbrOrientation": false,
        "accountThresholds": {
          "plusvibe": { "minBalance": 100, "action": "exclude" },
          "teamorouter": { "minBalance": 5, "action": "warn" }
        },
        "priceLimits": {
          "USD": { "inputMax": 30, "outputMax": 60, "action": "exclude" },
          "RUB": { "inputMin": 0.01, "action": "warn" }
        },
        "providerSites": {
          "openrouter": "https://openrouter.ai"
        },
        "groups": {
          "kimi": {
            "strategy": "free-fastest",
            "models": [
              "apimaster/kimi-k3.1-pro",
              "openrouter/moonshotai/kimi-k3.1-pro",
              { "providerID": "plusvibe", "id": "kimi-k3.1-pro", "variant": "max" }
            ]
          }
        }
      }
    }
  ]
}
```

Ручная группа применяется, если текущая модель сессии входит в неё. Необязательный `defaultGroup: "kimi"` направляет в эту группу каждый prompt, включая сессии с первоначально посторонней моделью. Массив `disabledModels: ["provider/model"]` исключает модели из роутинга без изменения credentials и глобальных настроек провайдера.

`askBeforeOverride: true` (по умолчанию) включает защиту ручного выбора модели: модель, которую установил не роутер, считается явным выбором пользователя, и на следующем prompt роутер не перехватывает её молча, а спрашивает — регистрирует вопрос (панель GUI «Защита ручного выбора», одно synthetic-уведомление без resume) и ждёт ответа через GUI или RPC `resolveOverrideRequest`: `keep` закрепляет ручную модель (роутер её больше не перемаршрутизирует, пока она не сменена), `override` переключает на предложенную. RPC `releaseManualSelection` снимает закрепление, а выбор через RPC `select` закрепляет модель автоматически. `askBeforeOverride: false` возвращает полностью автоматическую молчаливую маршрутизацию. Failover по лимитам провайдера выполняется молча независимо от флажка: это аварийное переключение, а не перехват предпочтений.

`accountThresholds` задаёт мониторинг остатка для каждого провайдера: `minBalance` — минимальный остаток на счёте в валюте самого аккаунта. `action: "warn"` (по умолчанию) только помечает выход за порог, `action: "exclude"` дополнительно исключает все модели провайдера из выбора роутера и ручного `select`. Исключение снимается автоматически при следующем обновлении, как только остаток вернётся в норму.

`priceLimits` задаёт глобальные границы цены за 1M токенов (input и output первого тарифа, как в каталоге) для каждой валюты аккаунтных цен: `inputMax`/`outputMax` — верхние границы, `inputMin`/`outputMin` — нижние. Границы применяются сразу ко всем моделям всех провайдеров с подтверждённым аккаунтным тарифом в этой валюте; значения в разных валютах никогда не смешиваются и не конвертируются. `action: "warn"` только помечает модель (`priceLimitBreached`), `action: "exclude"` убирает модели вне границ из роутинга — автопереключение на допустимые модели происходит при следующем выборе (prompt, failover, стратегия `cheapest`, ручной `select` отклоняется). Исключение снимается автоматически, когда цена вернётся в границы. Модели без подтверждённого аккаунтного тарифа по цене не помечаются и не исключаются.

`providerSites` задаёт адреса заглавных страниц провайдеров для публичного обнаружения цен без входа в аккаунт (например `"openrouter": "https://openrouter.ai"`). Роутер проверяет до шести стандартных путей (`/v1/models`, `/api/v1/models`, `/models`, `/api/models`, `/api/pricing`) и использует первый ответ с распознанными ценами; распознаются два формата: листы OpenRouter (`pricing.prompt`/`pricing.completion`, USD за токен) и прайсы шлюзов new-api/one-api (`model_ratio`/`completion_ratio` в quota-единицах, 500000 quota = $1 — конвенция проверена на публичных данных apimaster.ai; модели с поштучной тарификацией пропускаются). Формат распознаётся по структуре ответа, а не по имени провайдера. Принимаются лишь https-адреса (http — для localhost), встроенные в адрес credentials отклоняются. Запросы строго неаутентифицированные: ключи аккаунтов по-прежнему отправляются только на зафиксированные в коде API-origin. Результат кэшируется ~6 часов, после ошибки следующая попытка — через ~30 минут, а последний удачный снимок помечается устаревшим. Если адрес не задан вручную, роутер best-effort берёт `baseURL` из конфигурации провайдера в OpenCode; ручной `providerSites` всегда приоритетнее.

`cbrOrientation: true` включает приблизительную ориентировку по курсу ЦБ РФ в GUI и приблизительное сравнение разных валют в ранжировании `cheapest` (пересчёт в рубли по официальному курсу; это оценка порядка, а не котировка — провайдеры конвертируют средства по своим курсам). Границы цены и пороги остатка пересчёту не подлежат. По умолчанию флажок выключен и дополнительные сетевые запросы не выполняются.

## GUI и сохранение настроек

В OpenCode Desktop откройте **Settings → Model Autorouter** или выполните команду **«Открыть Model Autorouter»**. Пакет уже содержит собранный `gui-experimental` bundle; для установки из Git сборка не требуется.

Переключатели **Автоматическая маршрутизация**, **Автоматические группы**, **Продолжение после лимита**, **Защита ручного выбора модели** и переключатели моделей вызывают server RPC и меняют реальное поведение роутера. Выключение autorouter не выгружает сам серверный плагин: его RPC остаётся доступным для повторного включения. Включение и выключение самих серверных плагинов выполняется штатными средствами OpenCode.

Панель **«Защита ручного выбора»** появляется, когда есть нерешённые вопросы или закреплённые ручные модели: карточка вопроса предлагает кнопки **«Оставить …»** (закрепить ручную модель) и **«Переключить на …»** (подтвердить предложение роутера), карточка закрепления — кнопку **«Снять закрепление»**.

Изменения из GUI сохраняются через server plugin storage и применяются поверх стартовых `options` из `opencode.jsonc` после перезапуска. Кнопка **«Сбросить настройки»** удаляет сохранённый override и восстанавливает значения из конфигурации; метрики и credentials не изменяются. Изменение `rescanIntervalMs` пересоздаёт таймер без перезапуска.

В каталоге доступны все обнаруженные chat-модели, в том числе не входящие в группы. Кнопка **«Выбрать»** меняет модель выбранной открытой сессии, но не отправляет prompt. Каталог, настройки и выбор модели всегда используют server и `location` одной выбранной сессии.

Цены и остаток средств берутся из аккаунтных API провайдеров и всегда отображаются в валюте аккаунта (например, USD у OpenRouter/TeamoRouter и ₽ у PlusVibe) за миллион input/output-токенов первого тарифа. Подтверждённый аккаунтный тариф заменяет снимок OpenCode и помечается `live`; разные валюты не сравниваются численно, если не включена ориентировка по курсу ЦБ РФ — с ней ранжирование `cheapest` приближённо пересчитывает цены в рубли (оценка, а не котировка; отображение цен всегда в исходной валюте). Для провайдеров без подтверждённого аккаунтного API цена показывается только из публичного списка с сайта провайдера (пометка `public`), иначе не показывается (`—`) и не угадывается, а аккаунт помечается `unsupported`. При ошибке обновления сохраняется последний удачный снимок со статусом `stale` (для публичных цен — `public-stale`). Ключ отправляется только на зафиксированные в коде API-origin провайдеров: настройки провайдера в `opencode.jsonc` не могут перенаправить запрос аккаунта. Панель «Аккаунты провайдеров» показывает состояние каждого аккаунта, остаток средств и число моделей с подтверждённой ценой. Обновление аккаунтов не отправляет prompt провайдерам: запрашиваются только billing/pricing-эндпоинты.

Панель **«Публичные цены без входа»** перечисляет провайдеров каталога с полем адреса заглавной страницы и кнопкой **«Сохранить адрес»**. Рекомендуется указывать адрес заглавной страницы поставщика (например `https://openrouter.ai`) — роутер сам найдёт публичный список моделей с ценами; обнаруженный источник виден по бейджу «публичный тариф · N моделей» (при наведении — точный endpoint). Пустой адрес удаляет site и снимает публичные цены провайдера. Запросы к указанным адресам идут строго без ключей и cookies, поэтому публичные цены работают без входа в аккаунт; аккаунтный тариф всегда приоритетнее, а для точного мониторинга расходов панель предлагает кнопку **«Войти для точных расходов»**, открывающую форму ключа сейфа плагина.

Для OpenRouter, TeamoRouter и PlusVibe панель также предлагает кнопки **«Задать ключ»**/**«Заменить ключ»** и **«Удалить ключ»** с маскированным полем ввода. Сохранённый ключ шифруется AES-256-GCM в server storage плагина, имеет приоритет над ключом из connections OpenCode и используется только для аккаунтного API своего провайдера; источник активного ключа виден по бейджу «ключ плагина» или «ключ OpenCode». Значение ключа никогда не отображается обратно, не передаётся через RPC-ответы, статус или GUI. Честная граница защиты: шифрование охраняет от случайного просмотра дампов хранилища и утечек в логи, но не заменяет дисковое шифрование ОС — тот, кто имеет полный доступ к каталогу хранилища плагина и этой машине, может расшифровать ключ. Это необязательная возможность: без неё всё работает на ключах из connections OpenCode.

Кнопка **«Пороги»** у каждого аккаунта с подтверждённым API открывает форму минимального остатка в валюте аккаунта с выбором действия: «Только предупреждать» или «Предупреждать и исключать из роутинга»; карточка аккаунта содержит сводку заданных порогов, а при выходе за порог показывается бейдж «ниже минимума». Панель **«Границы цены для всех моделей»** задаёт верхние и нижние границы цены (input ≤ / output ≤ / input ≥ / output ≥) и действие для каждой валюты аккаунтных цен — сразу для всех моделей всех провайдеров в этой валюте; модель вне границ получает бейдж «вне границ цены», а при действии «исключать» — ещё и «исключена порогом». Автоматическое исключение влияет только на выбор роутера: пользовательские переключатели моделей не меняются, а исключение снимается само при следующем обновлении после возврата значений в норму.

Переключатель **«Ориентировка по курсу ЦБ РФ»** включает приблизительные эквиваленты «≈» для балансов и цен во всех валютах, в которых представлены цены и балансы аккаунтов, с датой курса, а также приблизительное сравнение разных валют в ранжировании `cheapest`: цены пересчитываются в рубли по официальному курсу ЦБ РФ и упорядочиваются численно (при равенстве решает измеренная скорость). Это сознательно приближённый метод: курс ЦБ — официальный, а не курс провайдера; провайдеры конвертируют средства по своим курсам, поэтому фактические расходы могут отличаться от оценки, — пересчёт лишь упорядочивает кандидатов и не является котировкой. Значения получены из публичного ежедневного API ЦБ РФ (запрос без credentials, кэш ~6 часов). Границы цены и пороги остатка пересчёту не подлежат и проверяются строго в валюте аккаунта/цены. Если курс какой-то валюты не загружен, разные валюты, как и прежде, численно не сравниваются; при недоступности курсов ориентировка не показывается и не выдумывается. Не обновлённые вовремя курсы сохраняются с явной датой публикации и пометкой об устаревании.

Скорость, TTFB и latency появляются после фактических шагов и не являются заранее заданным бенчмарком. Обновление каталога и цен не отправляет prompt провайдерам.

Строковая ссылка имеет формат `providerID/modelID` или `providerID/modelID#variant`. Model ID может сам содержать `/`: первый `/` отделяет провайдера. Модели, выключенные в OpenCode, в группу не попадают. Локально отключённая текущая модель остаётся в lookup группы, но исключается из выбора, поэтому роутер может переключиться на доступную альтернативу. Автоматические группы работают с базовой моделью и распознают её при выбранном variant; перечисление отдельных variant поддерживается в ручных группах.

### Стратегии

- `free-fastest` — сначала бесплатные модели, затем наибольшая измеренная скорость генерации, меньшие TTFB и latency. Модели без подтверждённой аккаунтной нулевой цены не считаются бесплатными.
- `fastest` — скорость независимо от стоимости.
- `cheapest` — фактическая стоимость на миллион сгенерированных токенов (OpenCode сообщает её в USD); до появления измерений используется аккаунтный тариф в валюте аккаунта. Кандидаты в разных валютах не сравниваются численно и выбор переходит к измеренной скорости — кроме случая, когда явно включена ориентировка по курсу ЦБ РФ: тогда цены приближённо пересчитываются в рубли по официальному курсу (оценка порядка, а не котировка; если курс хотя бы одной валюты не загружен, сравнение снова нечисленное). Неизвестная цена не считается нулевой.
- `manual` — порядок `models` в конфигурации; метрики не меняют приоритет.

До первых измерений стратегии скорости исследуют неизвестные модели. В автоматических группах альтернатива не должна уменьшать доступный context window и должна сохранять поддержку tools, если она нужна текущей модели. Для ручной группы context window считается явным выбором пользователя, но совместимость tools сохраняется.

## Failover и его ограничения

После ошибки лимита текущая модель исключается на `cooldownMs` или на серверный `Retry-After`. Каждая альтернатива перебирается не более одного раза в рамках автоматического выполнения. Новый prompt пользователя, успешное/прерванное выполнение, удаление сессии и cleanup отменяют соответствующее ожидающее продолжение.

При `resumeAfterFailover: true` плагин ждёт завершения неудачного execution и отправляет synthetic-продолжение по уже существующей истории. Это **не бесшовное соединение токенов уже начатого потока**: стандартный API такого продолжения не гарантирует. Модель получает инструкцию использовать историю и не повторять завершённые side effects, но автоматический анализ выполненных действий всё равно необходим.

При `resumeAfterFailover: false` модель переключается без synthetic-продолжения и без отмены штатного retry OpenCode.

Метрики и cooldown хранятся только в памяти процесса и сбрасываются при перезапуске. Плагин не обходит квоты и не создаёт новые учётные данные или подписки.

## RPC

- `status` — полный инвентарь моделей, варианты, группы, доступность, cooldown, эффективные настройки (включая `accountThresholds`, `priceLimits`, `cbrOrientation` и `providerSites`), состояния аккаунтов провайдеров (включая остаток средств, валюту и отметку `lowBalance`), отметки мониторинга по моделям (`priceLimitBreached`, `thresholdExcluded`), источник цены каждой модели в `models[].priceState` (`live`/`stale` — аккаунтный тариф, `public`/`public-stale` — публичный список с сайта провайдера), снимки публичных цен `publicPricing[]` (провайдер, точный endpoint, состояние, время загрузки, число моделей), при включённой ориентировке — блок `cbr` (дата курса, время загрузки, признак устаревания и курсы к рублю) и метрики без prompt, ответов, ключей и путей.
- `rescan` — немедленно повторяет обнаружение моделей и обновление аккаунтных тарифов/балансов, затем возвращает `status`.
- `configure` — применяет и сохраняет patch настроек; `{ "reset": true }` восстанавливает стартовую конфигурацию.
- `setAccountKey` — принимает `{ "providerID": "openrouter" | "teamorouter" | "plusvibe", "key": "…" }`, шифрует ключ в хранилище плагина и обновляет аккаунтные данные. Ответ содержит только `{ "stored": true, "providerID": … }`, значение ключа не возвращается.
- `clearAccountKey` — удаляет сохранённый ключ плагина; роутер возвращается к ключу из connections OpenCode, если он там есть.
- `select` — принимает `{ "sessionID": "…", "model": "provider/model#variant" }` и явно выбирает разрешённую модель из группы или полного инвентаря.

Например, через HTTP API текущего сервера (каталог проекта подставляется в `location[directory]`):

```sh
opencode api post '/api/rpc/opencode-model-autorouter/status?location%5Bdirectory%5D=C%3A%5Cpath%5Cto%5Cproject' --data '{"input":{}}'
```

Ответ находится в поле `output`. Те же методы доступны через `ctx.rpc` и `@opencode/client` без ручного формирования HTTP-обёртки.

## Тесты

Нужен Node.js 22.18+:

```sh
npm test
npm run typecheck
npm run test:gui
npm run test:memory
```

`test:gui` собирает `dist/gui-experimental.cjs` и проверяет загрузку bundle, регистрацию Settings page, команды и стилей. `test:memory` запускает 3000 циклов setup/cleanup с `--expose-gc` и проверяет освобождение hook/RPC-регистраций, подписок и ограниченную дельту heap. `test/robustness.test.ts` — жёсткие тесты на падения и утечки: мусорные и враждебные `providerSites`/configure-patch'и, падающий и «висящий» fetch, cleanup во время in-flight discovery, ограниченность снимков при churn адресов и 500 циклов discovery с `--expose-gc` без роста heap.

Проверка с фактически установленным SDK:

```sh
npm install --ignore-scripts
npm run test:sdk
```

`test:live` использует `OPENCODE_CLI`, запускает изолированный временный сервер, загружает плагин только для временного тестового проекта и проверяет обнаружение server/RPC/GUI, получение GUI bundle, полный инвентарь, живые аккаунтные тарифы и балансы подключённых провайдеров, конфигурацию и сброс порогов мониторинга, публичное обнаружение цен OpenRouter без входа (толерантно к недоступности сайта), отсутствие ключей в RPC-выводе и выбор модели без отправки prompt провайдерам. Лента курсов ЦБ РФ может быть недоступна из тестовой сети: live-тест принимает как корректный набор курсов, так и отсутствие блока `cbr` и логирует фактический результат.
