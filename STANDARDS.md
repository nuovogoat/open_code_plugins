# Стандарты инструментов экосистемы

Канонический стандарт (прочитать целиком перед разработкой инструментов):
**`C:\Projects\Kimi_code\TOOLING_STANDARDS_ver2.10.md`** (текущая версия: v2.10: явный выбор не перехватывается молча).

Рабочая копия: `C:\Users\Honor\Desktop\TOOLING_STANDARDS_ver2.10.md`.

Коротко: CLI + `.bat` (`<инструмент>_start.bat` — дефолтный вход в главное
окно); GUI по умолчанию на Tkinter, PySide6 — отдельным опциональным
модулем; i18n ru/en/de по ключам с авто-детектом и флажком в углу;
меню первого уровня — только открыватели окон; подтверждения разрушающих
действий; гейты и контрольные точки (пуш после каждой зелёной фазы);
нераспознанное — не данные (значения не выдумываются, невалидный вход
отклоняется, а не обрезается); кэш и backoff сбрасываются при смене входа;
секреты — только на захардкоженные origin; имя продукта — посимвольно
во всех идентификаторах, опечатку ловит тест, а не владелец; явный выбор
не перехватывается молча (автоматизация спрашивает перед заменой ручной
настройки, «оставить» закрепляет выбор, аварийный фолбэк видим).

Этот файл — указатель. Правки вносятся только в каноническую копию.
