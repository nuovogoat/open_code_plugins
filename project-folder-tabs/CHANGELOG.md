# Журнал изменений

Плагин использует [Semantic Versioning](https://semver.org/lang/ru/). Каждый
релиз помечается Git-тегом `project-folder-tabs/vX.Y.Z`.

## [1.4.1] - 2026-10-29

### Добавлено

- Длительный live soak-тест памяти сервера, handles, plugin instances, подписей и очистки сессий.
- Проверки отсутствия полных путей в реестре, его полной очистки и миграции при hot reload.

### Исправлено

- Долгоживущий общий реестр больше не хранит полные или нормализованные пути: только базовое имя, необходимые родительские сегменты и компактный ключ canonical root.
- Записи реестра прежнего формата безопасно мигрируют при hot reload без потери активных проектов.

## [1.4.0] - 2026-10-29

### Добавлено

- Минимальный фрагмент родительского пути при совпадении конечных имён проектов.
- Автоматическое восстановление короткого имени после исчезновения конфликта.
- Ограниченные числовые различители для полностью неразличимых путей.
- Проверки 1000 одноимённых папок, Unicode и реальных коллизий в OpenCode.

### Исправлено

- Общий реестр работает между изолированными module graph расположений OpenCode.
- Поздний ответ старого переименования не перезаписывает актуальную подпись.
- Подпапки одного canonical root не считаются разными проектами и не получают суффиксы.

## [1.3.0] - 2026-10-29

### Добавлено

- Deadline и abort для обращений к SDK, восстановление потока событий.
- Ограничение пагинации, single-flight rename и защита от накопления подписок.
- Lifecycle-, drift-, memory-, SDK- и живые стресс-тесты.
