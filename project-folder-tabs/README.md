# project-folder-tabs

Плагин OpenCode V2, который заменяет названия сессий именем корневой папки проекта. Desktop и другие клиенты показывают это имя на вкладках.

## Установка и обновление

```sh
opencode plugin add 'github:nuovogoat/open_code_plugins#main::path:project-folder-tabs'
opencode plugin check
opencode plugin update
```

При загрузке плагин переименовывает существующие сессии и перезаписывает их пользовательские названия. Новые сессии получают имя проекта автоматически.

## Безопасность

- Не читает файлы, переписку или секреты и не делает сетевых запросов.
- Пишет в журнал только общие ошибки без ID, путей, курсоров и ответов API.
- Удаляет опасные управляющие Unicode-символы, сохраняет ZWJ/ZWNJ и ограничивает имя 80 кодовыми точками.
- Использует официальный `@opencode/plugin` 2.1.4.

## Тесты

Нужен Node.js 22.18+; установка зависимостей для тестов ядра не требуется:

```sh
npm test
npm run test:brutal
```

`test:live` и `test:live:symbols` дополнительно проверяют реальный OpenCode через `OPENCODE_CLI`; создаваемые ими временные сессии и каталоги удаляются.
