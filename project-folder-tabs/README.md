# project-folder-tabs

Плагин OpenCode V2, который заменяет названия сессий именем корневой папки проекта. Desktop и другие клиенты показывают это имя на вкладках.

## Установка и обновление

```sh
opencode plugin add 'github:nuovogoat/open_code_plugins#main::path:project-folder-tabs'
opencode plugin check
opencode plugin update
```

При загрузке плагин переименовывает существующие сессии и перезаписывает их пользовательские названия. Новые сессии получают имя проекта автоматически.

## Безопасность

- Не читает файлы, переписку или секреты и не делает сетевых запросов.
- Пишет в журнал только общие ошибки без ID, путей, курсоров и ответов API.
- Удаляет опасные управляющие Unicode-символы, сохраняет ZWJ/ZWNJ и ограничивает имя 80 кодовыми точками.
- Использует официальный `@opencode/plugin` `latest`, без жёсткой привязки к версии OpenCode.

## Устойчивость к обновлениям OpenCode

Плагин рассчитан на переживание обновлений OpenCode без падений:

- `setup` сразу возвращает cleanup: зависший SDK-вызов или большая история не
  блокируют загрузку и выгрузку плагина.
- Все обращения к API ограничены deadline и отменяются при cleanup; обработчики
  abort и таймеры удаляются, поздние hook-регистрации освобождаются.
- Обрыв потока событий приводит к переподключению и повторной синхронизации;
  зависший итератор закрывается с ограниченным ожиданием.
- Пагинация ограничена 1000 страницами, повторные сессии и одинаковые
  одновременные rename-запросы не создают лишней работы.
- Отсутствие `session.list`/`session.update`, `session.hook`, `event.subscribe`
  или самого контекста приводит к деградации с общим сообщением в журнале,
  а не к ошибке загрузки плагина.
- Колбэк title-hook терпит замороженные, `null` и нестандартные события.

Локальная интеграция (без Git-пакета): положите каталог плагина в
`~/.config/opencode/plugins/project-folder-tabs` (или любой `.opencode/plugins/`)
— сервер подхватит его автоматически; проверка: `opencode plugin list`.

## Тесты

Нужен Node.js 22.18+; установка зависимостей для тестов ядра не требуется:

```sh
npm test
npm run test:brutal
npm run test:memory
```

`test:memory` запускается с `--expose-gc`: 3000 циклов setup/cleanup с зависшими
API проверяют закрытие подписок и ограниченную дельту heap.

Проверка entry-файла с фактически выбранной свежей версией SDK:

```sh
npm install --ignore-scripts
npm run test:sdk
```

`test:live` и `test:live:symbols` дополнительно проверяют реальный OpenCode через `OPENCODE_CLI`; создаваемые ими временные сессии и каталоги удаляются.
